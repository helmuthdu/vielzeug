# Document Task

## Use when

Update package documentation, README content, documentation recipes, or interactive REPL examples.

## Load

- root `AGENTS.md` (policy, safety, markers, commands)
- `.ai/reference/docs-template.md` for `docs/<name>/` pages
- `.ai/reference/readme-template.md` for `packages/<name>/README.md`
- `docs/AGENTS.md`
- relevant package `AGENTS.md`

## Preconditions

Confirm the package source and the documentation surfaces being edited exist. Use `[BLOCKED]` for unknown package scope or public behavior that source cannot confirm.

## Flow

1. Read the package manifest, public entry points, package contracts, and the selected docs surfaces.
2. Identify the package's documentation archetype and any validator contract (`.ai/reference/docs-template.md`) before applying the template.
3. Build a complete export/entry-point inventory, following re-export barrels where needed.
4. Run focused structural validation before editing to learn the baseline.
5. Update the API reference first, then affected overview, usage, README, recipes, and REPL examples.
6. Keep docs recipes (`docs/<name>/examples/`) distinct from REPL modules (`docs/.vitepress/theme/components/repl/`).
7. Update sidebar routes only when files or sidebar-linked headings change.
8. Build generated artifacts and run the validation for every touched surface.

## Surface rules

### Docs

Follow `.ai/reference/docs-template.md`. When a public export changed, inspect every recipe that names it; for a full documentation pass, inspect every recipe.

### REPL

Use plain JavaScript, one concept per snippet, top-level package imports only, visible output, and no DOM-output package examples. Rebuild package output before regenerating a stale REPL registry.

### README

Follow `.ai/reference/readme-template.md`. The description blockquote must equal `package.json#description`. Never hand-edit generated tool tables.

## Validation

| Surface                           | Required validation                                               |
| --------------------------------- | ----------------------------------------------------------------- |
| Docs                              | `pnpm validate:docs -- --package=<name>`, Codex build, docs build |
| REPL                              | `pnpm validate:repl -- --package=<name>`, docs build              |
| README generated by package build | package build                                                     |
| README structure                  | `pnpm validate:readme -- --package=<name>`                        |
