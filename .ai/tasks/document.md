# Document Task

## Use when

Update package documentation, README content, documentation recipes, or interactive REPL examples.

## Inputs

- `package`
- `surfaces`: `docs`, `repl`, `readme`
- `depth`: `affected` or `full`

## Load

- `.ai/core/policy.md`
- `.ai/core/workspace.md`
- `.ai/data/packages.json`
- `.ai/reference/docs-template.md` when `docs` is selected
- `docs/AGENTS.md`
- relevant package `AGENTS.md` chain

## Preconditions

Confirm package source and selected surfaces exist. Use `[BLOCKED]` for unknown package scope or public behavior that source cannot confirm.

## Flow

1. Read package manifest, public entry points, package contracts, and selected docs surfaces.
2. Read the structural contract from package metadata, then identify any source-backed content adaptation before applying the template.
3. Build complete export/entry-point inventory, following re-export barrels where needed.
4. Run focused structural validation before editing.
5. Update API reference first, then affected overview, usage, README, recipes, and REPL examples.
6. Keep docs recipes (`docs/<name>/examples/`) distinct from REPL modules (`docs/.vitepress/theme/components/repl/`).
7. Update sidebar routes only when files or sidebar-linked headings change.
8. Build generated artifacts and run selected validation.

## Surface rules

### Docs

Follow `.ai/reference/docs-template.md`. Inspect standard pages or documented profile adaptations. Under `affected` depth, search only recipes naming changed exports; under `full`, inspect every recipe.

### REPL

Use plain JavaScript, one concept per snippet, top-level package imports only, visible output, and no DOM-output package examples. Rebuild package output before regenerating a stale REPL registry.

### README

Keep package README aligned with public entry points and generated sections. Never hand-edit generated tool tables.

## Validation

| Surface                           | Required validation                                               |
| --------------------------------- | ----------------------------------------------------------------- |
| Docs                              | `pnpm validate:docs -- --package=<name>`, Codex build, docs build |
| REPL                              | `pnpm validate:repl -- --package=<name>`, docs build              |
| README generated by package build | package build                                                     |

## Output

- `[VERIFY] <claim>: <reason>`
- `[BLOCKED] <decision>`
